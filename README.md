# GW2-Event-API
A simple to work with API of Gw2 Events, when they occur and for how long without needing to keep track of cycles.

Attached is a demo python program which parses through event_api.json and lists the next 5 spawns from the data selected, in the demo it takes the info from "bosses" changing this field to for example "lws4" gives all living world season 4 events
